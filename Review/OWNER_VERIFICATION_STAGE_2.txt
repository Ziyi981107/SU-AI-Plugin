HOW TO RUN THE CHECKLIST (S2-BLOCK-005-compliant setup)
========================================================

CRITICAL (per S2-BLOCK-005 fix):
  - Use disposable test geometry via `Entities#add_line` (or
    `add_edges`) inside a freshly created Group / ComponentInstance.
  - Never edit production / source CAD for test setup.
  - Never modify the test Group's entity material / layer / persistent_id
    after creating it (to keep source-integrity fingerprint stable).
  - Capture a deterministic source fingerprint BEFORE running Preflight:
      - entity counts (Groups, Components, Edges)
      - all persistent_ids (sorted)
      - endpoint coordinates of every Edge (sorted)
      - container transformations (4x4 matrix, hex)
      - layer/tag assignments (sorted)
  - Run Preflight via `SUAnalysis::Extension::PreflightRunner.run(sel)`.
  - Capture the SAME fingerprint AFTER analysis.
  - Diff must be empty (modulo selection state, which is allowed to
    change but is NOT a model mutation).
  - Cleanup: erase the disposable Group via `group.erase!` (the user's
    own action, not part of the Analyzer).

Setup helper (Ruby Console, fresh empty model):

  model = Sketchup.active_model
  entities = model.active_entities
  test_group = entities.add_group
  test_group.entities.add_line([0,0,0], [10,0,0])
  test_group.entities.add_line([10,0,0], [10,5,0])
  test_group.entities.add_line([10,5,0], [0,5,0])
  test_group.entities.add_line([0,5,0], [0,0,0])

G. Source integrity fingerprint (BLOCK-005 evidence)
   Paste this helper into Ruby Console, then run it before AND after a
   Preflight run on the selected test_group; the two hashes must match.

   # -- Begin fingerprint helper --
   def su_fingerprint(root)
     return nil unless root.respond_to?(:persistent_id)
     {
       kind:               root.typename,
       persistent_id:      root.respond_to?(:persistent_id) ? root.persistent_id : nil,
       transformation:     root.respond_to?(:transformation) ? root.transformation.to_a : nil,
       layer:              root.respond_to?(:layer) ? root.layer.name : nil,
       edges:              if root.respond_to?(:entities)
                            root.entities.grep(Sketchup::Edge).map do |e|
                              {
                                start: e.start.position.to_a,
                                finish: e.end.position.to_a,
                                pid:   e.persistent_id
                              }
                            end.sort_by { |h| h[:pid].to_s }
                          else
                            []
                          end,
       groups:             if root.respond_to?(:entities)
                            root.entities.grep(Sketchup::Group).map do |g|
                              su_fingerprint(g)
                            end
                          else
                            []
                          end,
       components:         if root.respond_to?(:definition)
                            [{ definition_name: root.definition.name, definition_pid: root.definition.persistent_id }]
                          elsif root.respond_to?(:entities)
                            root.entities.grep(Sketchup::ComponentInstance).map do |c|
                              { definition_name: c.definition.name, definition_pid: c.definition.persistent_id }
                            end
                          else
                            []
                          end
     }
   end
   # -- End fingerprint helper --

   1. Run: `fp_before = su_fingerprint(test_group)`
   2. Run Preflight on test_group selection.
   3. Run: `fp_after = su_fingerprint(test_group)`
   4. Verify `fp_before == fp_after` (Ruby == on the two hashes).
   Expected: identical fingerprints. No source mutation.

  core/ + compatibility/ + extension/ were verified by automated
  post-2.2 syntax sweep (no &., no frozen_string_literal, no pattern
  matching, no numbered params, no endless methods). See commit

  stays SketchUp-independent.
