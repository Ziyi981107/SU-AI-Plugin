STAGE 1 BUGS DISCOVERED AND FIXED
==================================

Two latent Stage 1 bugs were masked by the lack of a working Ruby
runtime in the previous session. Both fixed in 5e32ab1:

1) core/synthetic_factory.rb
   - Was: `class SyntheticFactory` + `module_function`
   - Fix: `module SyntheticFactory` + `module_function`
   - Reason: `module_function` is a Module method; calling it inside a
     class body raises NameError. Tests use SyntheticFactory.rectangle(...)
     directly, so the methods must be on the module (or as `self.`).

2) tests/runner.rb
   - Was: TestCase + TestResult + helper methods, but no dispatcher
   - Fix: added `Tests.run!(filter = nil)` which iterates selected
     cases, prints PASS/FAIL/ERROR lines + summary, returns 0/1.
   - Reason: tests/run_all.rb called `Tests.run!(ARGV[0])` which
     NoMethodError'd before any test could run.
