2. IMPLEMENTED
==============

V1.0 Read-only CAD Analyzer delivers the full closed loop
promised by PI_TASK_001 §1:

  User selects Group / Component / Edges in SketchUp
    → extension/loader.rb#on_analyze_selection
    → extension/preflight_runner.rb#build_snapshot
      (SU-side walker: traversal + transform accumulation + PID
       path + active-edit-context seed + per-Edge rescue)
    → extension/analyzers_runner.rb#run
      ├─ core/preflight.rb#PreflightAnalyzer.run
      ├─ 4 analyzers (Duplicate / Short / OpenEndpoint / Gap)
      ├─ core/issue_normalizer.rb (raw -> canonical)
      ├─ core/issue_enricher.rb (deterministic ids + locatable)
      ├─ core/issue_registry.rb (validate + hold + summary)
      └─ core/analysis_result.rb (immutable frozen wrapper)
    → extension/ui_bridge.rb (Symbol -> String keys, JSON-safe)
    → extension/dialog_runner.rb (HtmlDialog)
    → extension/html/app.js (textContent render, locatable-gated
       click handlers)
    → User can click an Issue row to Locate, which uses
       extension/issue_locator.rb (host-side glue) +
       core/issue_locator_policy.rb (pure-Ruby policy) to
       resolve the SourceToken chain to Model entities and
       zoom the camera.

  All of the above is READ-ONLY on the source CAD. The only
  mutations permitted by the analysis path are:
    - model.selection (view-state, allowed by R003)
    - model.active_view.zoom (camera, allowed by R003)
    - HtmlDialog (modeless UI, not a model mutation)
  All other SketchUp model state (entities, layers, materials,
  definitions, attributes, hidden, soft) is UNTOUCHED.

10. SOURCE INTEGRITY
====================

  Original source geometry modified: NO

Verified by the source_integrity synthetic test:

  - snapshot a fake selection (5 entities)
  - run the full pipeline (AnalyzersRunner.run)
  - fingerprint entities (object_id + persistent_id + class)
  - compare before/after -> identical

EdgeRecord.start_point / .end_point are stored as Array<Float>
(world-coord copies), not as references to the source vertex
position. The build_snapshot walker reads vertex.position once
and constructs a new world-coord triple per EdgeRecord; it
never assigns back to source entities.

IssueRegistry holds Symbol/Hash representations of detected
issues. IssueEnricher aligns SourceTokens to EdgeRecord by
edge_id; SourceTokens are derived from the SourceReference
attached to each EdgeRecord. The model-side SketchUp entities
are NEVER written.

IssueLocator (host-side glue) calls:
  - model.selection.clear / model.selection.add (view-state;
    permitted by R003)
  - view.zoom (camera; permitted by R003)
  - find_entity_by_id / resolve_pid_path (read-only; returns
    Model entities but does not mutate them)

No code path mutates:
  - entities (add / remove / move / rotate)
  - layers (add / rename / reorder)
  - materials (assign / change)
  - definitions (modify / repaint)
  - hidden / soft / dictionary entries
  - attributes / dynamic attributes
  - model.active_path (always read-only)
  - model.tags (always read-only)
  - model.styles (always read-only)

  Per PI_TASK_001 §17: "绝不修改原始几何". This contract is
  honored. PI_TASK_001 §22.10: "如果 YES, 本任务直接视为失败".
  Result: NO source modification -> task NOT failed.
