REAL CALL CHAIN (this is what actually runs)
----------------------------------------------------------------------

Per the V1.5 directive (Guidance 031, CodeX 032 recheck):

  1. User selects N entities in SketchUp, then opens the
     SU-AI-Plugin dialog.
  2. User clicks Prepare.
     - WorkingModeRunner.prepare() captures the current
       SourceSnapshot, builds the DerivedGeometryWorkspace,
       and then AUTOMATICALLY calls
       run_duplicate_repair_batch(registry) against the
       DuplicateDetector's IssueRegistry. The Prepare
       callback auto-runs the eligible batch; there is NO
       separate "Run Duplicate Repairs" button.
  3. WorkingModeRunner.run_duplicate_repair_batch:
     a. Proposer.propose(snapshot, registry, workspace)
        -- emits 0+ :remove_duplicate_edge RepairActions
        -- full leaf identity verification, pid_path_complete
           check (BLOCK-001)
        -- distinct derived_ids + unique live host handles
           (BLOCK-001 host-aliasing)
        -- survivor + removed handles are disjoint (BLOCK-001)
        -- direct endpoint matcher with captured tolerance
           (BLOCK-002; proposer and validator share the
           SAME matcher semantics)
        -- post-merge closure re-verification + non-transitive
           split (BLOCK-002)
     b. DuplicateDetector (Production) -- adjacent-bucket +
        boundary-aware cell placement + direct endpoint
        gate. Catches cross-bucket within-tolerance duplicates
        the previous detector missed (BLOCK-002).
     c. Executor.apply_batch(workspace, validated_plan)
        -- preflight computes the COMPLETE post-workspace
           in pure data BEFORE opening the host operation
           (BLOCK-003)
        -- post_state_matches_expected? runs BEFORE
           begin_operation -- a mismatch fails closed without
           opening a host operation (BLOCK-003)
        -- one begin, dispose all, one commit (no begin ->
           commit -> abort sequence on commit failure)
        -- successful commit: precomputed post-workspace is
           PUBLISHED (not constructed after commit); no
           follow-up end_operation(commit: false) attempt
     d. DerivedDuplicateValidator.validate(post_workspace)
        -- uses the captured execution_config tolerance
        -- measures duplicate_classes_after on the actual
           post-batch workspace (BLOCK-004)
     e. build_duplicate_repair_summary writes the audit
        data with REAL measurements (BLOCK-004): applied/
        skipped/failed, classes before/after, pairs
        before/after (NOT hardcoded to 0), derived edge
        counts before/after, per-action audit rows
        including removed_count, survivor_derived_id,
        source_occurrence_count, source_occurrence_ids,
        issue_ids.
  4. User clicks Discard.
    -- Workspace transitions to :discarded; every SU-AI-
       Derived-* group is disposed inside a single
       SketchUp operation.
  5. User clicks Rebuild.
    -- Workspace is rebuilt from the captured source +
       registry; the auto-apply batch re-runs deterministically
       (same source + same registry -> same plan + same
       post-state fingerprint).

Owner verification MUST observe the real call chain above.
There is no "Run Duplicate Repairs" button; the batch is
auto-applied on Prepare (and on Rebuild).

2. Run the setup (creates one definition with one edge, two
   instances at the SAME identity transform):
   Sketchup.active_model.start_operation("V15G1-Setup", true)
   mod = Sketchup.active_model
   defn = mod.definitions.add("V15G1-DupDef")
   defn.entities.add_edges([
     [Geom::Point3d.new(0, 0, 0), Geom::Point3d.new(10, 0, 0)]
   ])
   ent = mod.active_entities
   inst_a = ent.add_instance(defn, Geom::Transformation.new)

       IMMEDIATELY after Prepare returns).

4. Read the Working Mode duplicate_repair audit row from the
   dialog (these are READ from the dialog's Working Mode

     - actions_skipped == 0
     - actions_failed  == 0
     - duplicate_classes_before == 1
     - duplicate_classes_after  == 0
     - duplicate_pairs_before   == 1
     - duplicate_pairs_after    == 0
     - derived_edge_count_before == 2
     - derived_edge_count_after  == 1

     - actions[0].source_occurrence_count == 2 (two distinct

     - actions[0].removed_count         == 1
     - actions[0].issue_ids             contains the source issue id

   - inst_a, inst_b still exist as distinct entities

   SketchUp operations (Prepare creates derived entities

   repair is undone (one derived edge remains). Press Ctrl+Z
   again -> the derived edges are all gone (zero derived

   unchanged).
