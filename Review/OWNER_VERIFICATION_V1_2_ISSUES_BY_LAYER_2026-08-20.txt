PURPOSE
-------

Per Q002=A, real-SketchUp verification is Owner's responsibility.
This checklist is a FOCUSED addition to the V1.0 Stage 6 and
V1.1 Gate 2 checklists. It covers ONLY the V1.2 "Issues by
Layer" surface — the new `<details id="layer-issues-section">`
in the dialog.

  - Dialog renders a new top-level section 'Issues by Layer'.
  - Section is BELOW the per-issue-type groups block and ABOVE
    the V1.1 Layers section.
  - Section is CLOSED by default; summary pre-populated.
  - Bucket per non-empty layer, in canonical role order
    (Dimension -> Annotation -> Guide -> Construction -> Unknown),
    visible-before-hidden within a role, then name ASC.

    singular/plural wording.
  - Issues inside buckets reuse the existing issue-row renderer;
    locatable issues still call Locate; non-locatable issues
    still register no click handler.
  - Existing V1.1 Layers rows remain inert (no click handler).
  - Analysis remains read-only. No model mutation, no layer
    visibility flip, no entity creation / deletion.

This checklist re-uses the same dev-tree / RBZ load path
convention established in the V1.1 Gate 2 checklist. The V1.0
+ V1.1 baselines do NOT need to be re-verified in full if

  # -- Begin V1.2 fingerprint helper --
  def v12_count_geometry_recursive(entities)
    counts = { edges: 0, faces: 0, groups: 0,
               components: 0, definitions: 0 }
    entities.each do |e|
      case e
      when Sketchup::Edge
        counts[:edges] += 1
      when Sketchup::Face
        counts[:faces] += 1
      when Sketchup::Group
        counts[:groups] += 1
        counts.merge!(v12_count_geometry_recursive(e.entities)) { |_, a, b| a + b }
      when Sketchup::ComponentInstance
        counts[:components] += 1
        counts.merge!(v12_count_geometry_recursive(e.definition.entities)) { |_, a, b| a + b }
      end
    end
    counts
  end

  def v12_fingerprint(model)
    {
      edges:           v12_count_geometry_recursive(model.entities)[:edges],
      groups:          v12_count_geometry_recursive(model.entities)[:groups],
      layers_visible:  model.layers.map { |l| [l.name, l.visible?] }
    }
  end

  fp_before = v12_fingerprint(Sketchup.active_model)
  puts "PRE = #{fp_before.inspect}"
