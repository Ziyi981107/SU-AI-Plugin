本目录用途
==========
所有 Implementation / Coding Agent 遇到的需要外部决策的问题
都写成 .txt 文件放在本目录,等待外部回答。

外部回答者:Codex (OpenAI 模型)。

回答会由 Product Owner 转写到:

  D:\Projects\SU-AI-Plugin\Prompt\

Agent 将在下一轮读 Prompt/ 中的回答后继续工作。

------------------------------------------------------------
文件命名约定
------------------------------------------------------------

Q<NNN>_<topic>.txt
    单一外部决策问题。NNN 从 001 开始递增。

README / WORKFLOW_PROTOCOL.txt
    本说明文件。供 Codex 一次性读懂协议。

不再使用其它命名。

------------------------------------------------------------
每个 Q 文件的统一结构
------------------------------------------------------------

每个 Q 文件应至少包含以下段落,缺一不可:

  STATUS:           OPEN | ANSWERED | CANCELLED
  QUESTION:         一句话问题
  CONTEXT:          为什么会出现这个问题 (引用 PI_TASK_001 段号)
  OPTIONS:          A. ... B. ... C. ... (不要列与本问题无关的选项)
  RECOMMENDATION:   Agent 当前倾向的选项 + 简短理由
  IMPACT:           不同选择对项目的影响
  REFERENCES:       相关任务章节 / AGENT.md 章节

Agent 在 STATUS=OPEN 时写入。
Agent 收到 Codex 回答并落地后,把 STATUS 改为 ANSWERED,
并在文件末尾追加一段:

  ANSWER (received <YYYY-MM-DD>):
    <Codex / Owner 给出的回答要点>

------------------------------------------------------------
给 Codex 的读取顺序建议
------------------------------------------------------------

1. 读本 WORKFLOW_PROTOCOL.txt
2. ls Review/ 得到所有 Q 文件
3. 按 STATUS=OPEN 的文件读取并回答
4. 回答按 Prompt 目录现有任务文档风格回复
   (可参考 Prompt/PI_TASK_001_V1_READONLY_CAD_ANALYZER.txt
    的语气和粒度)
5. Product Owner 会把你的回答作为新文件落到 Prompt/
