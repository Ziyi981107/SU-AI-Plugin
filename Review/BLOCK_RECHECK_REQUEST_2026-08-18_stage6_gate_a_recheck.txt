BLOCK-001 — Leaf was incorrectly counted as structural nesting
=========================================================

Problem: structural_depth = active_path_count + ancestry_count + 1
counted the leaf itself as a structural level. This contradicted the
locked contract that root leaf has depth 0.

Fix (CodeX Review 015 BLOCK-001 v3):
  - structural_depth = active_path_count + ancestry_count (leaf EXCLUDED)
  - expected_pid_count = structural_depth + 1 (the leaf is +1)
  - Root leaf: depth 0; one enclosing container: depth 1
  - Active edit context entities counted normally
  - updates affect: core/structural_facts.rb, tests/test_structural_facts.rb

Files in this fix:
  core/structural_facts.rb          (M)
  tests/test_structural_facts.rb    (M, rewritten)
  tests/test_issue_locator_policy.rb (M, +2 integration tests)

Integration tests added (CodeX Round 014 directive):
  - complete root -> :inst_path_leaf
  - incomplete root + entityID -> :entity_id
  Both pipe StructuralFacts -> SourceReference -> IssueEnricher ->
  IssueLocatorPolicy to verify the contract end-to-end.

BLOCK-002 — Issue IDs still used transient identity and unstable counter
====================================================================

Problem A: geometry_signature fallback to entity_id and object_id.
  - Removed. The fallback chain now uses ONLY deterministic analysis
    data:
      1. quantized coordinates (when location is provided)
      2. sorted edge_ids (when edge_ids are present)
      3. constant NO_SOURCE_KEY (last-resort; shared by all sources)

Problem B: counter assigned in input order without sorting.
  - enrich_all now sorts each type bucket by
    IssueIdAssigner.canonical_source_keys BEFORE assigning counter.
  - Reversed/shuffled input produces the same issue_id for the same
    logical Issue.

  - updates affect: core/issue_id_assigner.rb, core/issue_enricher.rb

Files in this fix:
  core/issue_id_assigner.rb          (M)
  core/issue_enricher.rb            (M)
  tests/test_issue_id_assigner.rb   (M, +3 adversarial tests)
  tests/test_issue_enricher.rb      (M, +2 permutation tests)

Adversarial tests added:
  - no-PID + no-location -> no-source key (no entity_id/object_id)
  - no-PID + sorted edge_ids -> deterministic edges key
  - location fallback ignores entity_id
  - counter is order-independent (reversed input)
  - counter is order-independent (shuffled input)
