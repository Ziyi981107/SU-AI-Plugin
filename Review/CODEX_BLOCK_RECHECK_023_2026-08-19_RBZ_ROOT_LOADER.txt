  M extension/su_ai_plugin.rb
      Refactored to the standard SketchUp extension pattern:
        - require 'sketchup.rb'
        - require 'extensions.rb'
        - unless file_loaded?(__FILE__)
            extension = SketchupExtension.new(
              'SU-AI-Plugin',
              'su_ai_plugin/main'
            )
            Sketchup.register_extension(extension, true)
            file_loaded(__FILE__)
          end
      Per CodeX 023 BLOCK-023-001: the second arg to
      `SketchupExtension.new` is now a String ('su_ai_plugin/
      main'), NOT an Array. The path is the relative
      no-extension target (SketchUp resolves either .rb or
      encrypted formats).
      Per CodeX 023 BLOCK-023-002: the registration is
      GUARDED by `unless file_loaded?(__FILE__)` so repeated
      re-evaluation (REPL reload, file_unloaded + sentinel
      reset) registers exactly once. The `file_loaded(__FILE__)`
      key is the absolute path of the .rb file itself, NOT a
      hand-written constant.

  A tests/stubs/sketchup.rb
      New: test stub for the SketchUp Ruby API. Defines the
      `Sketchup` module so `defined?(Sketchup)` is true in
      the test env. Does NOT define `SketchupExtension` (that
      lives in tests/stubs/extensions.rb).

  A tests/stubs/extensions.rb
      New: type-validating stub for `SketchupExtension` and
      `Sketchup.register_extension`. The class raises on
      contract violations (Array target, non-Boolean load_now,
      non-SketchupExtension ext arg) so the BLOCK-023-001 fix
      cannot regress without a loud test failure.

  M tests/runner.rb
      Adds `tests/stubs` to $LOAD_PATH so the registration
      loader's `require 'sketchup.rb'; require 'extensions.rb'`
      resolves to the stubs in the test env.

  M tests/test_loader.rb
      Updates `stub_sketchup_with_selection` to define
      `register_extension` directly on the new `sk` module
      (the requires inside the entry-point are idempotent and
      the first require applied the method to a different
      Sketchup module). The BLOCK-023-001 / 002 tests now
      use the type-validating stubs from tests/stubs/:
        - 'test_loader (BLOCK-023-001): registration loader
           passes String target, not Array' asserts:
            * exactly one SketchupExtension constructed on
              first load
            * target is exactly 'su_ai_plugin/main'
            * target is a String (not Array)
        - 'test_loader (BLOCK-023-002): repeated root-loader
           evaluation registers exactly once' asserts:
            * first load constructs + registers once
            * second load (file_loaded? == true) skips
              both the construct AND the register

        - 'test_loader (BLOCK-023-002): registration loader
           itself does not execute Boot.boot!' asserts:
