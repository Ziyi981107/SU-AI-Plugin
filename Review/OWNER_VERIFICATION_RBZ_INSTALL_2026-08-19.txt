INSTALL PROCEDURE
==================

  1. Open SketchUp 2020 (or 2017 if verifying Gate 1).

  2. Window > Extension Manager (SketchUp 2017+) OR
     Window > Preferences > Extensions (older builds).
     Confirm SketchUp is NOT loaded with any prior SU-AI-Plugin
     state. If a previous build is present, click "Uninstall"
     on it first.

  3. Click "Install Extension...". Navigate to:
        D:\Projects\SU-AI-Plugin\dist\SU-AI-Plugin.rbz

  4. SketchUp may show a security prompt ("You are about to
     load an extension that is not signed..."). Click "Yes" /
     "Load Anyway" (the .rbz is unsigned; this is the locked
     posture for V1.0 — no .rbz signing infrastructure yet).

  5. After install, SketchUp reports the extension is enabled.
     **CRITICAL**: confirm the menu item appears at the
     EXPECTED LOCATION per the standard SketchUp extension
     contract:
        Plugins > SU-AI-Plugin > Analyze selection

     If the menu does NOT appear, the .rbz packaging is broken.
     STOP and report. Do NOT bypass the install by loading
     `extension/su_ai_plugin.rb` from the dev tree — that tests
     the dev tree and DOES NOT verify the install.

  6. Confirm the file layout under SketchUp's Plugins/ directory.
     The .rbz extracts into:
        SketchUp/Plugins/su_ai_plugin.rb          (root registration loader)
        SketchUp/Plugins/su_ai_plugin/            (same-named support folder)
          SketchUp/Plugins/su_ai_plugin/main.rb   (boot target)
          SketchUp/Plugins/su_ai_plugin/loader.rb
          SketchUp/Plugins/su_ai_plugin/core/...
          SketchUp/Plugins/su_ai_plugin/compatibility/...
          SketchUp/Plugins/su_ai_plugin/html/index.html
          SketchUp/Plugins/su_ai_plugin/html/app.js
          SketchUp/Plugins/su_ai_plugin/html/style.css

     The entry-point (`su_ai_plugin.rb`) is a SIBLING of the
     support folder (`su_ai_plugin/`), NOT a child. The support
     folder contains all operational code (main.rb, loader.rb,
     core/, compatibility/, html/).

POST-INSTALL BOOT SMOKE
=========================

  1. CLOSE SketchUp and RE-OPEN it. SketchUp loads extensions
     at startup; the install was a one-time copy. To verify
     the extension is registered, restart SketchUp.

  2. Open the Ruby Console (Window > Ruby Console).

  3. Confirm the entry-point loaded without error. Look for any
     [SU-AI-Plugin] boot failed: ... lines. Expected: none.

  4. Confirm the menu item appears at:
        Plugins > SU-AI-Plugin > Analyze selection

     If the menu is registered, the install is functioning.

  5. (Optional, advanced) Confirm the constants surface from
     the Ruby Console:
        SUAnalysis::Extension::Loader.registered?
        SUAnalysis::Core::PreflightReport.instance_methods(false)
     Expected: no NameError on the constants above; the Loader
     is loaded; PreflightReport exposes pure-Ruby metrics only.
