This step uses a ONE-SOT SELF-RESTORING patch (V14-RUNTIME-BLOCK-001

original method AND raises the injected failure. NO `begin /

======================================================================
PASTE-RUNNABLE RUBY CONSOLE SNIPPET (V14-8, ONE-SOT)
======================================================================

  require 'D:/Projects/SU-AI-Plugin/extension/su_ai_plugin/compatibility/su_derived_workspace_adapter'

  ADAPTER  = SUAnalysis::Compatibility::SketchupDerivedWorkspaceAdapter
  ORIGINAL = ADAPTER.instance_method(:begin_operation)

  ADAPTER.class_eval do
    define_method(:begin_operation) do |_model, label:|
      ADAPTER.class_eval do
        define_method(:begin_operation, ORIGINAL)
      end
      raise StandardError, 'v14-gate-2-injected-failure'
    end
  end

  # At this point, the patch IS installed. Click "Discard"
  # first (to clear any current workspace), then click
  # "Prepare". Observe:
  #   - dialog: state = "failed", last_error visible
  #   - model: NO new SU-AI-Derived-* groups
  #   - ruby: no exception escapes (the workspace caught it)

  ADAPTER.instance_method(:begin_operation) == ORIGINAL
  # => true (patch has been restored by the one-shot)
