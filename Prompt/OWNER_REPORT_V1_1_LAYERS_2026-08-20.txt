NITS OBSERVED ON SU2020
=======================

NIT 1 (cosmetic, UI):
  Layers row text rendered as "1 edge3 issues" with no space
  or separator between the edge and issue counters. Owner
  expected: "1 edge \u00B7 3 issues" (with a visible middle-dot
  separator). Also: pluralization was off ("1 edges" instead
  of "1 edge"; "0 issues" was OK by coincidence).

  Cause: the two count spans were siblings with only a flexbox
  `gap: 8px` between them. When the host dialog rendered with
  gap 0 (or near 0), the text collapsed visually. There was
  also no central plural formatter.

  Status: FIXED in this branch (Agent fix commit
    fix(v1.1): layer-row separator + plural form (per Gate 2 V1.1 NIT)
  ). Re-run expected on top of the fix commit.

NIT 2 (fixture, doc):
  Three issues in the OWNER_VERIFICATION_V1_1_LAYERS_2026-
  08-20.txt setup helper:
    2a. Named layers were assigned only to the parent Group,
        not to the Edge objects. Relying on group inheritance
        can leave edges on Layer0 in some SketchUp builds; the
        Agent's recommendation is explicit per-edge assignment
        for cross-version robustness (SU2017+ baseline).
    2b. The hidden layer was named "TXT-HIDDEN" which does NOT
        match the Annotation rule `/(anno|t?ext|label)/i` (no
        `anno`, no `ext` substring in `txt`, no `label`
        substring in `hidden`). It would be classified as
        :unknown, not :annotation, breaking L4.
    2c. Each V1.1 fixture was a single edge. A single edge
        produces 2 Open Endpoint issues, so the fixture was
        NOT a "0 issues" fixture as documented.

  Status: FIXED in this branch. The fixture now uses a
  `make_rect(entities, layer_obj, x, y)` helper that builds
  a 4-edge closed rectangle and explicitly assigns the named
  layer to each of the four edges. The hidden layer is now
  named "TXT-LABEL-HIDDEN" (matches via `label`).
  doc: OWNER_VERIFICATION_V1_1_LAYERS_2026-08-20.txt setup
  helper updated. L3 / L4 / L5 step descriptions updated to
  reference the new fixture names and closed-rectangle shape.

NIT 3 (informational, no action required):
  Closed rectangles all share a corner vertex coordinate with
  their immediate neighbor, which produces 4 separate Edges
  with no shared geometry. Per the V1.0 dedup policy, two
  coincident edges (e.g. shared wall between two rectangles)
  would surface a Duplicate Candidate, but our fixtures are
  spatially disjoint so this is moot. No code action needed.
